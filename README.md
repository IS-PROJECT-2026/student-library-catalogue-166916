# Project : Student Library Catalogue

A functional web-based library catalogue designed for students to browse, search, filter, and interact with books available in the library.

## About the Project

The Student Library Catalogue provides students with a simple and user-friendly way to explore resources from the library.

The application allows students to search for books, filter books by category, view detailed information about books, add books to their favorites, and interact with the borrowing functionality.

User preferences such as favorite and borrowing status are stored using the browser's localStorage, allowing the information to remain available after refreshing the page.

## Features

- Browse the book catalogue
 - Search books by:
 - Title
 - Author
 - Category
 - Filter books by category
- View detailed information about individual books
- Add and remove books from favourites
- Borrow available books
- Display book availability status
- Persist favourites and borrowing information using localStorage
Responsive design

## How to Use

1. Open `index.html` in a modern web browser.
2. Browse the available books in the catalogue.
3. Use the search bar to search by title, author, or category.
4. Use the category filter to display books from a specific category.
5. Click View Details to see more information about a book.
6. Add books to your favourites using the favourite button.
7. Click Borrow Book to borrow an available book.
8. Refresh the page to verify that favorite and borrowing information are preserved using localStorage.

## Deployment

The project can be deployed as a static website because it uses HTML, CSS, and JavaScript and does not require a backend server.
